========================================
    هورايزن HR - نظام إدارة الموارد البشرية
    للمصانع والشركات
========================================

== متطلبات التشغيل ==
- Node.js (الإصدار 18 أو أعلى)
- Windows 10/11 أو Linux

== خطوات التشغيل ==

[الطريقة الأولى - أسهل]
1. انقل المجلد كله على جهازك
2. افتح موجه الأوامر (CMD) داخل المجلد
3. اكتب:  npm install
4. بعد ما يخلص، اكتب:  npm run electron
5. هيشتغل التطبيق زي أي برنامج عادي!

[الطريقة الثانية - بالمتصفح]
1. انقل المجلد كله على جهازك
2. افتح موجه الأوامر (CMD) داخل المجلد
3. اكتب:  npm install
4. اكتب:  npm run build
5. افتح الملف:  dist/public/index.html
   بالمتصفح (Chrome أو Edge)

== ملاحظات مهمة ==

1. البيانات بتتخزن في المتصفح (localStorage)
   يعني مش هتمسح لما تسكر البرنامج

2. التطبيق بيشتغل بدون إنترنت بالكامل
   بعد ما يتحمل أول مرة

3. لو عايز تغير مكان حفظ البيانات:
   - شغل التطبيق
   - روح لصفحة "الإعدادات"
   - هتلاقي خيار تصدير/استيراد البيانات

4. حسابات الدخول الافتراضية:
   ---------------------------------
   | المستخدم  | كلمة المرور  |
   ---------------------------------
   | admin     | admin123    |
   | supervisor| super123    |
   | accountant| acc123      |
   | worker    | work123     |
   ---------------------------------

== تثبيت Node.js ==
لو Node.js مش متثبت على جهازك:
1. ادخل على:  https://nodejs.org
2. حمل النسخة LTS
3. ثبتها زي أي برنامج عادي
4. افتح CMD واكتب:  node --version
   لو ظهر رقم الإصدار يبقى تمام

== للمساعدة ==
البيانات بتتخزن محلياً على جهازك.
مفيش بيانات بتطلع بره الجهاز.
